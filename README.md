# 💰 Budgetory

> 소비 내역을 카테고리별로 관리하고, 예산 설정과 소비 패턴 시각화를 통해 체계적인 소비 습관 형성을 돕는 iOS 가계부 앱

## 📌 프로젝트 소개

**Budgetory**는 사용자의 소비 내역을 카테고리별로 기록하고 분석할 수 있는 가계부 앱입니다.

단순히 지출 내역을 기록하는 것에 그치지 않고, 카테고리별 소비 금액과 비율을 시각적으로 제공하여 사용자가 자신의 소비 습관을 쉽게 파악할 수 있도록 돕습니다.

또한 각 카테고리에 월별 예산을 설정하고 현재 지출 금액과 비교함으로써 계획적인 소비를 실천할 수 있습니다.

## ✨ 주요 기능

### 1. 소비 내역 등록

* 소비 금액, 날짜, 카테고리, 메모 입력
* 식비, 교통비, 쇼핑 등 카테고리별 소비 내역 관리
* 등록한 소비 내역 수정 및 삭제

### 2. 소비 내역 조회

* 날짜별 소비 내역 확인
* 카테고리별 소비 내역 조회
* 월별 전체 지출 금액 확인

### 3. 소비 패턴 시각화

* 카테고리별 소비 금액과 비율 제공
* 차트를 활용한 월별 소비 패턴 시각화
* 가장 많은 소비가 발생한 카테고리 확인

### 4. 카테고리별 예산 설정

* 각 소비 카테고리에 월별 예산 설정
* 설정한 예산 대비 현재 소비 금액 확인
* 남은 예산 및 예산 사용률 제공

### 5. 소비 현황 관리

* 이번 달 총소비 금액 확인
* 예산 초과 여부 확인
* 소비 내역과 예산을 한 화면에서 비교

## 🚀 실행 방법

### 1. 저장소를 클론합니다.

```bash
git clone <repository-url>
```

### 2. 프로젝트 디렉터리로 이동합니다.

```bash
cd Budgetory
```

### 3. Xcode에서 프로젝트를 실행합니다.

```bash
open Budgetory.xcodeproj
```

CocoaPods를 사용한 경우에는 다음 파일을 실행합니다.

```bash
open Budgetory.xcworkspace
```

### 4. 실행할 시뮬레이터 또는 디바이스를 선택한 후 프로젝트를 빌드합니다.

```text
Command + R
```
